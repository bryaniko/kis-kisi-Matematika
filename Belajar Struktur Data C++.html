1

Variabel, konstanta, dan tipe data

Variabel itu seperti kotak berlabel. Isinya boleh diganti kapan saja, tetapi labelnya tetap.

Cerita: dompet Dimas. Dimas punya dompet bernama uang. Isinya awalnya 10.000. Lalu ia menerima 5.000 dari ibunya. Sekarang isi dompetnya 15.000. Labelnya tetap uang, tetapi isinya berubah.

int uang = 10000;   // dompet berisi 10000
uang = uang + 5000; // ditambah 5000
cout << uang;      // tampil: 15000

Tipe data: jenis isi kotak

Tipe menentukan jenis isi yang boleh masuk, seperti laci untuk baju atau laci untuk makanan.

Komputer menyimpan 'A' sebagai angka 65. Maka kode ini mencetak 66, bukan A:

Konstanta: kotak yang tidak boleh diisi ulang

Cerita: jumlah hari dalam seminggu. Angka 7 tidak akan berubah. Maka kita kunci dengan const.

const int HARI_SEMINGGU = 7;
HARI_SEMINGGU = 8;   // ERROR: konstanta tidak boleh diubah

Tebak: fungsi hitung() dipanggil tiga kali. Apa yang tercetak?

    static int n = 0;   // static: nilai tetap tersimpan
    n++;
    cout << n << ' ';
}
Output: 1 2 3

Variabel biasa akan kembali ke nilai awal setiap kali fungsi dipanggil. Variabel static tidak, karena nilainya terus tersimpan.

Ingat

Beri nilai awal setiap variabel. Variabel yang belum diisi bisa berisi angka acak.

2

Operator

Operator adalah simbol untuk berhitung dan membandingkan, seperti tombol kalkulator.

Contoh 1: belanja

Dina membeli 3 buku. Harga satu buku 5.000. Berapa total yang harus dibayar?

int harga = 5000;
int jumlah = 3;
int total = harga * jumlah;   // 5000 x 3
cout << total;               // tampil: 15000

Contoh 2: membagi kue

Ada 7 potong kue untuk 2 orang. Setiap orang dapat berapa? Dan berapa sisanya?

int kue = 7;
int orang = 2;
cout << kue / orang;   // tampil: 3   (bagian bulat)
cout << kue % orang;   // tampil: 1   (sisa)

Ingat: / mengambil hasil bagi, sedangkan % mengambil sisanya. Kalau mau hasil 3,5, tulis 7.0 / 2.

Contoh 3: boleh masuk bioskop?

Aturannya: umur minimal 13 tahun, dan harus membawa tiket. Operator && berarti "dan". Keduanya harus benar.

int umur = 15;
bool punyaTiket = true;
bool boleh = umur >= 13 && punyaTiket;
cout << boleh;   // tampil: 1 (benar)

Lacak: operator gabungan

int a = 10;
a += 5;    // a = a + 5
a %= 4;    // a = a % 4
Barisa
int a = 10;10
a += 5;15
a %= 4;3

Tebak: berapa nilai y setelah baris ini?

int y = 5;
y ^= 7;
y = 2

Operator ^ membandingkan bit per bit. Pada 0101 dan 0111, bit yang berbeda hanya tersisa di posisi 2, hasilnya 0010.

Jebakan: = dan ==

x = 5 berarti "simpan 5 ke x". x == 5 berarti "apakah x sama dengan 5?". Tertukar satu tanda saja bisa membuat program salah.

3

Pilihan dan perulangan

Pilihan (if) membuat program memilih jalan. Perulangan (loop) mengerjakan hal yang sama berkali-kali.

Contoh 1: lulus atau remedial?

Syarat lulus adalah nilai 75 atau lebih. Jika tidak, harus remedial.

int nilai = 60;
if (nilai >= 75) {
    cout << "Lulus";
} else {
    cout << "Remedial";
}
nilai = 60 → Remedial
nilai = 80 → Lulus

Contoh 2: nilai huruf

Program mengecek dari atas ke bawah. Begitu ada yang benar, pengecekan berhenti.

if (nilai >= 80) {
    cout << "A";
} else if (nilai >= 70) {
    cout << "B";
} else {
    cout << "C";
}

Dengan nilai 85, cek pertama sudah benar, jadi hasilnya A. Nilai 85 tidak perlu dicek ke baris berikutnya.

Contoh 3: hitung dari 1 sampai 3

Bayangkan kamu menghitung anak tangga. Setiap putaran, angka bertambah 1 sampai batasnya.

for (int i = 1; i <= 3; i++) {
    cout << "Langkah " << i << endl;
}

Contoh 4: berhenti saat ketemu

Kamu mencari kunci di antara 10 laci. Begitu ketemu, kamu berhenti mencari. break bekerja seperti itu.

for (int i = 1; i <= 10; i++) {
    if (i == 4) break;      // ketemu, berhenti
    cout << i << ' ';
}
Output: 1 2 3

Tebak: apa output loop ini?

for (int i = 1; i <= 10; i++) {
    if (i % 3 == 0) break;
    cout << i << ' ';
}
Output: 1 2

Saat i = 3, syarat i % 3 == 0 benar, lalu break menghentikan seluruh loop.

Jebakan

Titik koma setelah if atau for, seperti if (x > 0);, membuat badan kosong. Lupa break di switch membuat case berikutnya ikut jalan.

Tipe data lanjutan

Tipe lanjutan dipakai untuk menyimpan banyak data sekaligus, atau data yang punya beberapa bagian.

Array: deretan loker

Cerita: loker sekolah. Ada tiga loker bernomor 0, 1, dan 2. Setiap loker menyimpan nilai ulangan satu siswa. Untuk membuka loker nomor 1, kita tulis nilai[1].

int nilai[3] = {80, 90, 75};
cout << nilai[1];   // tampil: 90 (loker nomor 1)
nilai[2] = 85;      // ganti isi loker nomor 2

Menjumlah semua isi array

int total = 0;
for (int i = 0; i < 3; i++) {
    total += nilai[i];
}
cout << total;   // 80 + 90 + 75 = 245

Struct: formulir isian

Satu buku punya judul, pengarang, dan harga. Daripada membuat tiga variabel terpisah, kita bungkus jadi satu formulir bernama Buku.

struct Buku {
    string judul;
    int harga;
};

Buku b;
b.judul = "Petualangan";
b.harga = 40000;
cout << b.judul << " " << b.harga;

Pointer: alamat rumah

Cerita: Rumah Sinta ada di Jalan Melati nomor 7. Kamu tidak membawa rumahnya, hanya alamatnya. Dari alamat itu kamu bisa datang dan melihat isinya. Pointer menyimpan alamat sebuah variabel.

int x = 3;
int *p = &x;   // p menyimpan alamat x
*p = 7;        // datangi alamatnya, isi diganti 7
cout << x;    // tampil: 7

Reference: nama panggilan

Sinta dipanggil "Sinta", "Nta", atau "Bu Guru". Semua nama itu menunjuk orang yang sama. Reference adalah nama lain untuk variabel yang sama.

int x = 3;
int &r = x;   // r adalah nama lain dari x
r += 2;       // x juga berubah
cout << x;   // tampil: 5

Stack: tumpukan piring (LIFO)

Piring ditumpuk satu per satu. Yang diambil pertama adalah piring paling atas, yaitu yang terakhir ditaruh. Itulah Last In, First Out.

AksiTumpukan (dari bawah ke atas)Top
push(14)1414
push(8)14, 88
push(6)14, 8, 66
pop()14, 88
pop()1414

Queue: antrean loket (FIFO)

Yang datang duluan, dilayani duluan. Itulah First In, First Out.

AksiAntrean (depan ke belakang)
push("Agung")Agung
push("Wisnu")Agung, Wisnu
pop()Wisnu (Agung sudah dilayani)

Tebak: setelah push 14, push 8, push 6, lalu pop dua kali, berapa nilai top sekarang?

Top = 14

Pop pertama membuang 6, pop kedua membuang 8. Yang tersisa paling atas adalah 14.

Linked list: permainan berantai

Setiap anak memegang tangan anak di sebelahnya. Kalau mau menyisipkan satu anak di tengah, cukup lepas dan pegang tangan yang baru. Anak lain tidak perlu pindah tempat.

Array atau linked list?

Array cepat dibuka lewat nomor loker, tetapi sulit disisipi di tengah. Linked list mudah disisipi, tetapi harus dilalui satu per satu dari awal.

5

Fungsi, dekomposisi, abstraksi, dokumentasi

Fungsi adalah resep kecil. Kamu beri bahan, dia mengerjakan satu tugas, lalu mengembalikan hasilnya.

Contoh 1: fungsi sapa

void sapa(string nama) {
    cout << "Halo, " << nama << "!";
}

int main() {
    sapa("Ani");     // tampil: Halo, Ani!
    sapa("Budi");    // tampil: Halo, Budi!
    return 0;
}

Kode penyapaan cukup ditulis sekali, lalu dipanggil berkali-kali. Itu manfaat utama fungsi.

Contoh 2: fungsi yang mengembalikan hasil

Fungsi rataRata menerima tiga nilai, lalu mengembalikan rata-ratanya. return adalah kata yang mengirim hasil kembali ke pemanggil.

double rataRata(int a, int b, int c) {
    return (a + b + c) / 3.0;
}

int main() {
    double hasil = rataRata(80, 90, 75);
    cout << hasil;   // tampil: 81.6667
}

Dekomposisi: pecah masalah

Cerita: membuat nasi goreng. Kamu tidak memasak semuanya sekaligus. Ada tahap menyiapkan bahan, menumis bumbu, memasak nasi, lalu menyajikan. Tiap tahap bisa dikerjakan sebagai fungsi tersendiri.

  1. Tulis tujuan program dalam satu kalimat: menghitung luas dan keliling persegi panjang.
  2. Pecah jadi input, proses, dan output.
  3. Setiap bagian yang masih besar, pecah lagi sampai jadi satu fungsi.
  4. Di main(), panggil fungsi-fungsi itu satu per satu seperti membaca daftar belanja.

Abstraksi: cukup tahu apa, bukan bagaimana

Saat menyetir mobil, kamu cukup tahu fungsi setir, gas, dan rem. Kamu tidak perlu paham isi mesinnya. Itulah abstraksi: menyembunyikan detail yang tidak perlu dipakai.

// Pemakai cukup memanggil ini:
double luas = hitungLuas(4, 3);   // 12

// Tidak perlu tahu rumus di dalamnya.

Dokumentasi: jelaskan alasannya

/**
 * Menghitung jarak titik B ke garis AC.
 * Luas segitiga ABC = (p x l) / 2 = (AC x t) / 2
 * maka t = (p x l) / AC
 */
double jarakBkeAC(double p, double l) {
    return hitungLuas(p, l) / hitungDiagonal(p, l);
}

Komentar yang baik menjelaskan mengapa dan rumusnya. Komentar yang hanya mengulang kode, seperti i++ // tambah i, tidak banyak membantu.

Tebak: dengan p = 4 dan l = 3, berapa jarakBkeAC(4, 3)?

2.4

Luas = 4 x 3 = 12. Diagonal = 5. Maka 12 / 5 = 2.4.

Ingat

Satu fungsi, satu tugas. Kalau sulit memberi nama, mungkin fungsinya mengerjakan terlalu banyak hal.

6

Rekursi

Rekursi adalah fungsi yang memanggil dirinya sendiri, dengan masalah yang makin kecil setiap kali.

Cerita: menghitung orang dalam barisan

Kamu ingin tahu berapa orang di barisan ini. Kamu tanya orang paling belakang: "Berapa orang di depanmu?" Dia tanya orang di depannya, begitu terus sampai orang paling depan. Dia menjawab "0". Lalu setiap orang menambah 1 dan mengirim jawabannya ke belakang.

Dua bagian wajib

Base case

Titik berhenti. Kasus paling kecil yang langsung dijawab, misalnya orang paling depan.

Recursive case

Langkah yang memanggil dirinya lagi, tetapi dengan masalah yang lebih kecil.

Contoh 1: hitung mundur

void hitungMundur(int n) {
    if (n == 0) {                  // base case
        cout << "Selesai";
        return;
    }
    cout << n << ' ';            // cetak angka sekarang
    hitungMundur(n - 1);           // recursive case
}

hitungMundur(3);   // tampil: 3 2 1 Selesai

Lacak panggilannya

PanggilannYang dilakukan
hitungMundur(3)3cetak 3, lalu panggil hitungMundur(2)
hitungMundur(2)2cetak 2, lalu panggil hitungMundur(1)
hitungMundur(1)1cetak 1, lalu panggil hitungMundur(0)
hitungMundur(0)0base case, cetak Selesai, berhenti

Contoh 2: faktorial

Faktorial 4 adalah 4 x 3 x 2 x 1. Tetapi kita bisa melihatnya sebagai 4 kali faktorial 3. Begitu juga faktorial 3 adalah 3 kali faktorial 2, dan seterusnya.

int faktorial(int n) {
    if (n <= 1) return 1;            // base case
    return n * faktorial(n - 1);   // recursive case
}

Lacak: faktorial(4)

  1. faktorial(4) butuh 4 x faktorial(3)
  2. faktorial(3) butuh 3 x faktorial(2)
  3. faktorial(2) butuh 2 x faktorial(1)
  4. faktorial(1) = 1, ini base case. Sekarang hasil kembali ke atas.
  5. faktorial(2) = 2 x 1 = 2
  6. faktorial(3) = 3 x 2 = 6
  7. faktorial(4) = 4 x 6 = 24

Tebak: berapa hasil faktorial(5)?

120

5 x 4 x 3 x 2 x 1 = 120. Sama seperti tadi, hanya lebih panjang.

Lupa base case = fungsi tidak pernah berhenti

Tanpa if (n == 0), hitungMundur akan terus turun ke angka negatif sampai program crash karena stack overflow.

7

Overloading

Overloading artinya satu nama fungsi dipakai untuk beberapa versi. Komputer memilih versi yang cocok dari argumen yang kamu kirim.

Cerita: tombol "cetak" di printer. Tombolnya sama, tetapi kamu tidak perlu mengingat tiga nama berbeda untuk mencetak foto, dokumen, dan amplop. Printer tahu cara mencetak sesuai isinya.

Contoh: fungsi luas

int luas(int sisi) {                 // persegi
    return sisi * sisi;
}
int luas(int panjang, int lebar) {   // persegi panjang
    return panjang * lebar;
}
double luas(double jariJari) {       // lingkaran
    return 3.14159 * jariJari * jariJari;
}

int main() {
    cout << luas(4);      // 16, versi persegi
    cout << luas(4, 6);   // 24, versi persegi panjang
    cout << luas(7.0);    // 153.938, versi lingkaran
}

Dari jumlah argumen dan tipenya, komputer tahu versi mana yang harus dipakai.

Apa yang boleh dibedakan?

Yang berbedaBoleh?Contoh
Jumlah parameterbolehluas(int) dan luas(int, int)
Tipe parameterbolehtampil(int) dan tampil(string)
Hanya tipe hasiltidak bolehint hitung(int) dan double hitung(int)
Kenapa "hanya tipe hasil" tidak boleh?

Saat kamu menulis hitung(5); tanpa mengambil hasilnya, komputer tidak tahu versi mana yang kamu mau. Karena itu, perbedaannya harus ada di parameter.

Tebak: ada dua versi cetak(int) dan cetak(double). Apa yang terjadi saat memanggil cetak(5L)?

Error: ambigu

Angka 5L bisa diubah ke int maupun double dengan jumlah langkah yang sama. Komputer tidak bisa memilih, jadi terjadi error.

Ingat

Rekursi dan overloading bisa dipakai bersama. Setiap versi overload boleh memanggil dirinya sendiri.

Cek pemahamanmu

Coba jawab dulu dalam kepala, baru lihat jawabannya.

Ada kotak dengan label nilai, isinya 70. Lalu ditambah 10. Berapa isinya sekarang?

80. Labelnya tetap, isinya yang berubah.

Antrean loket: Ani datang dulu, lalu Budi. Siapa yang dilayani pertama?

Ani. Antrean bekerja dengan prinsip FIFO.

Mengapa faktorial(0) tidak boleh diabaikan saat menulis rekursi?

Karena base case harus menangani kasus paling kecil. Tanpanya, pemanggilan tidak berhenti.

Apa bedanya const dan #define?

const punya tipe dan dicek compiler. #define hanya teks pengganti.
